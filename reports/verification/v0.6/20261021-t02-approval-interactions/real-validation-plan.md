# 新飞书交互的待批准实测方案

状态：仅准备，尚未打开入口、改动飞书配置或发送消息。

目标为既有独立 OriaTest、测试群“招商oria平台测试群”和此前确认的测试审批人。先只读核验应用、群唯一性及既有身份映射，任何变化均停止，不自动新增角色或权限。真实通道使用隔离 Mock/Fixture、临时 SQLite 和独立合成发起人，不访问企业业务数据或执行投放。

批准范围建议：Cloudflare 临时 HTTPS 回调入口最多 30 分钟，仅开放 POST `/v1/ingress/feishu/events`，其余路径拒绝；更新该独立应用的临时回调地址并校验，不调整权限、共享应用或事件类型。只读发现最多四次请求，只发送一张合成审批卡片及同一消息的一次激活 PATCH；无自动重投。

卡片内容：标题“招商发布审批”，摘要“等待审批”，合成活动编号 `campaign-interaction-check`，合成时间与有效期，以及“批准仅记录决定，后续执行仍须重新校验权限和方案版本”“本次审批终止，不执行此项操作；修改方案后须重新申请审批”。六段摘要形成两页；控件为“批准”“查看详情”和固定字段的“拒绝并提交理由”。不点击批准，拒绝理由固定为“合成验收：预算需调整”。

实测步骤：

1. 发送无控件 JSON 2.0 卡片，获得消息回执后持久绑定并激活。
2. 重启本地接收端，点击查看详情、下一页及上一页，确认每页五段上限、编号稳定、决定控件可继续使用，审批仍 pending，业务 outbox 不增加。
3. 提交上述合成拒绝理由，确认真实签名/AES 请求通过，单一审批变为 rejected，决定审计与 outbox 各增加一次，拒绝表单与批准按钮消失。
4. 同一已捕获请求只在内存中经完整 ASGI 验证路径复验一次；不冒充平台重投，不保存 raw body。确认没有额外决定、绑定或 outbox。
5. 成功、失败、结果不明或到时均关闭临时入口并核验进程/监听停止；只保存状态、计数、必要 ID 摘要及用户显示确认。

前置仍需上述具体外部写入和窗口的明确批准，以及可用的受限本地凭证文件。未批准前不执行本方案。该卡只证明新飞书交互，不替代 PostgreSQL、本地 Job/Graph、双 worker 或 V0.5-T07 Live 评测。
